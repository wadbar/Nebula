# 🌌 NEBULA OS: Media Matrix Intelligence

**Version:** 4.0.0-PRO  
**Architecture:** Enterprise Node.js / React / TypeScript / Vite  

NEBULA OS is a hyper-optimized, high-fidelity Open Source Intelligence (OSINT) Media Discovery & Playback engine. It is designed to index, scrape, aggregate, and playback media nodes (video, audio, text, ROMs, metadata) from multiple distributed archives using advanced Artificial Intelligence and Extreme Proxy capabilities.

## 🚀 Extreme Optimizations Applied

### 🧠 Server & Node.js Engine (The Core)
- **Extreme V8 Node Tuning:** Enforced `--max-old-space-size=4096`, `--optimize-for-size`, and aggressive Garbage Collection (`--gc-interval=100`) via `package.json` to prevent crashes during millions of telemetry ops.
- **Socket Networking Potency:** Max sockets boosted to `50,000`, absolute TLS `keepAlive` bindings, and deep compression algorithms `(compression level: 9)` to ensure bandwidth is preserved when indexing terabytes of data.
- **Fail-Safe Process Architecture:** Process-level error traps (`uncaughtException`, `unhandledRejection`) to guarantee absolute zero-crash tolerance in the main execution thread.
- **Parallel Tolerance Scrapers:** All OSINT module fetchers utilize `Promise.allSettled`, isolating failing nodes dynamically without breaking the scraping pipeline.

### 🌐 Frontend DOM & Media Players (The Glass)
- **Advanced VLC DOM Bypass (Potent Mode):** Provides raw OS-level injection to external VLC cores `(vlc://)`, stripping standard browser buffering limits and natively passing jitter variables `(--network-caching=5000)`.
- **Preload Topology (Next-Node):** The intelligence engine automatically fetches the head layout and network handshakes for the *next* item in your Active Playlist before it plays, bringing UI buffering and load latency near **0ms**.
- **Material 3 / React Strict Rendering:** All recursive maps enforce unique cryptography signatures (`id`) removing generic array indices, dropping repaint bottlenecks.

### 🤖 AI Grounding Models
- **Tri-Fold AI Provider Chain:** Integrates `@google/genai` with fallback support for Ollama and Nvidia inference endpoints for zero downtime.
- **Extreme Precision API Settings:** Output restricted through aggressive `topK: 40`, `topP: 0.95`, and `maxOutputTokens: 8192` allowing maximum intelligence retrieval in structured JSON formatting without hallucination overlap.
